# Template Learning Operational Summary

Canonical source: `../../../protocols/template-observation.md`.

1. Extract structure and visual evidence from user-approved samples.
2. Separate format evidence from business content.
3. Classify each Observation as `fact`, `inference`, `conflict`, or `unknown`.
4. Record `confidence`, evidence, and source references.
5. Ask for user confirmation before updating a Format Profile.
6. Resolve inheritance with map deep-merge, list replacement, and cycle rejection.
7. Run neutral fixtures before activating the updated Profile.

A format sample never proves a current business fact.
