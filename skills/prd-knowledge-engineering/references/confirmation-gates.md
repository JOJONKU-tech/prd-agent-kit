# Confirmation Gates Operational Summary

Canonical source: `../../../protocols/confirmation-gates.md`.

- Gate 1 controls knowledge-base writes and canonical domain-skill generation.
- Skill installation is a separate authorized side effect.
- Gate 2 controls online document creation or update.
- Gate 2 confirmation is bound to `plan_sha256`.
- Material plan changes invalidate confirmation.
- A refusal stops the corresponding side effect; do not switch tools to bypass it.
- API success requires structural or browser verification before completion.
