# Source Priority Operational Summary

Canonical source: `../../../protocols/source-priority.md`.

Business truth priority:

```text
Current user confirmation
> current meeting conclusion or MRD
> current business knowledge
> current system documentation
> historical PRD
> agent general knowledge
```

Format priority:

```text
User-designated standard
> user-confirmed representative PRD
> neutral provisional profile
```

Never use a format example as proof of a business fact. Never use a business document's lack of formatting as proof that a format rule does not exist. Escalate current-source conflicts and all high-risk rule conflicts.
