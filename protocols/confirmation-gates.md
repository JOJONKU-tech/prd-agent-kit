# Confirmation Gates Protocol

## 目标

确认门用来控制真实副作用，而不是走形式。V1定义两个内容确认门：Gate 1控制知识库写入和Skill安装，Gate 2控制在线文档发布或更新。

## 通用规则

- 确认必须绑定当前计划摘要或哈希；
- 计划发生实质变化后确认失效；
- 阻断问题未解决时不得提供“确认执行”选项；
- 用户拒绝后立即停止对应副作用，不得换工具绕过；
- 只读分析、临时内存整理和本地预检不需要内容确认门；
- 凭据配置、沙箱写入等独立副作用仍需单独授权。

## Gate 1：知识库写入确认

### 触发时机

素材审计和缺口访谈完成、但尚未写入正式知识库时触发。

### 必须展示

```text
业务域与边界
角色与主链路
系统、页面与关键对象
术语、指标与规则
来源冲突及处理结果
保留的unknown/provisional
格式来源与Profile状态
计划创建/更新的文件
业务专属Skill能力
知识库路径
原始资料reference/copy模式
```

### 确认后允许

- 创建或更新知识库文件；
- 写入Router；
- 写入Format Profile；
- 生成Canonical Domain Skill。

### 确认后仍不允许

- 未经单独授权安装Skill到Agent目录；
- 配置MCP凭据；
- 发布在线文档；
- 覆盖非本项目管理的同名Skill。

### 确认失效条件

- 业务域改变；
- 新增或删除计划文件；
- 原始资料模式改变；
- 格式来源改变；
- 冲突处理结果改变；
- Skill能力或安装范围改变。

## Gate 2：发布确认

### 触发时机

PRD IR、Renderer预检和本地预览完成，但尚未创建或更新在线文档时触发。

### 必须展示

```text
PRD标题与内容版本
功能需求和图片数量
阻断/非阻断问题
目标平台、空间和目录
新建、更新或新建版本
最终文档标题
Format Profile和Renderer
Required/Preferred能力
降级清单
将上传的资产数量
明确副作用
预览文件
发布后验收方式
```

### Plan Hash

发布计划必须生成`plan_sha256`。用户确认记录：

```yaml
confirmation:
  status: confirmed
  plan_sha256: ""
  confirmed_at: ""
```

执行前重新计算哈希。不一致时确认失效，必须重新展示Gate 2。

### 确认失效条件

- PRD IR内容改变；
- 发布目标改变；
- 新建/更新操作改变；
- 文档标题改变；
- Renderer或Profile改变；
- 降级项改变；
- 上传资产数量改变；
- 验收策略改变。

## 阻断条件

出现以下任一情况，不得请求Gate 2确认：

- IR Schema或语义校验失败；
- 存在`blocking + open`问题；
- Required格式能力不支持；
- Renderer预览失败；
- MCP Adapter未通过授权的沙箱写入；
- 目标空间无法定位；
- Asset不可读取；
- 更新失败转新建版本，但尚未向用户说明。

## 新建与更新

- 只有用户明确提供目标文档ID或URL时才能更新；
- 未指定目标时新建；
- 发现同名文档不自动覆盖；
- 更新目标无法读取时改为新建V2/V3；
- 操作变化必须重新进入Gate 2。

## 发布后状态

```text
planning
awaiting_confirmation
publishing
partial
published_unverified
published_verified
failed
```

API成功不等于完成。至少通过MCP结构读取或浏览器只读验收之一；两者都不可用时，需要用户明确确认，确认前保持`published_unverified`。

## 拒绝与撤回

用户拒绝时：

1. 停止对应写入或发布；
2. 保留本地草稿和检查结果；
3. 不重复询问同一计划；
4. 用户修改范围后生成新计划；
5. 新计划必须重新确认。

用户确认后、执行前可以撤回；一旦远程写入开始，只能停止后续步骤并报告已发生副作用，不承诺自动回滚或删除。
