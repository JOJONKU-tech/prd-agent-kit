# Event Configuration Process

1. Event Operator opens a template.
2. User selects an event format.
3. Relay settings appear only for Relay Ladder.
4. User enters valid team size and checkpoint count.
5. User saves a draft.
6. Event Admin reviews and publishes.

Existing formats remain unchanged.
