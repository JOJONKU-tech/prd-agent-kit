# Glossary

- Event template: reusable configuration for one competition format.
- Relay Ladder: fictional checkpoint relay format configured by team size and checkpoint count.
- Event Operator: user who creates and edits drafts.
- Event Admin: user who reviews and publishes templates.
- Cumulative scoring: fixed Relay Ladder scoring mode that aggregates checkpoint results.
