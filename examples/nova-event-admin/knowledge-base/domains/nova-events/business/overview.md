# Business Overview

Nova Events supports Event Operators, Event Admins, and Scorekeepers.

The template flow is create → configure → save draft → publish. Event Operators may save valid drafts; Event Admins may publish. Relay Ladder adds checkpoint-based team configuration without changing existing formats.
