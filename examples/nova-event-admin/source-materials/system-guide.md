# Nova Event Admin System Guide

## Event Templates / Basic Information

Current fields:

- Event name: required text, up to 60 characters.
- Event format: required single choice.
- Current options: Solo Sprint and Team Circuit.
- Status: Draft or Published.

The Basic Information page saves changes as a draft. Publishing is a separate action available to Event Admin users.

The current system has no Relay Ladder option and no conditional format panel.
