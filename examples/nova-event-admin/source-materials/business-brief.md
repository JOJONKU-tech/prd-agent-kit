# Nova Events Business Brief

Nova Events is a fully fictional service that helps community organizers configure small competitions.

## Users

- Event Operator: creates and edits event templates.
- Event Admin: reviews and publishes templates.
- Scorekeeper: records results after an event starts.

## Main process

```text
Create event template
→ choose event format
→ configure format fields
→ save draft
→ Event Admin publishes
```

This source defines the business scope and roles. It does not define detailed field ranges.
