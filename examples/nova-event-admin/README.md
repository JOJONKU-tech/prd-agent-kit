# Nova Event Admin — End-to-End Example

This is a fully fictional B2B product example created from scratch for `prd-agent-kit`.

The company, product, systems, roles, fields, rules, screenshots, PRD content, document identifiers, and URLs are invented. It is not a renamed copy of any real company material.

## Scenario

Nova Event Admin is a fictional operations console for community competition organizers. This example adds a new event format named **Relay Ladder** and demonstrates conditional configuration, validation, publishing permissions, and source traceability.

## Chain

```text
source-materials
```

The receipt and online document URL are simulated fixtures. They are not a real publication and prove no live MCP integration.
