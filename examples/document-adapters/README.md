# Document Adapter Examples

These files demonstrate the Adapter schema after a successful sandbox verification. They are not pre-authorized integrations and their illustrative Tool names will not automatically match a real MCP server.

Before use:

1. inspect the current MCP Tool Schemas;
2. generate a mapping proposal;
3. get user confirmation;
4. run read-only checks;
5. get separate sandbox write authorization;
6. replace all example target/document identifiers with the real sandbox results;
7. validate the Adapter again.

Never copy `write_verified` or `structure_verified` as proof. Those statuses are earned by real execution in the user's environment.
